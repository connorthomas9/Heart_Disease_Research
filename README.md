## Overview
In this project, we will be analyzing some data from a sample of anonymous patients who were evaluated for heart disease at the `Cleveland Clinic Foundation`.

The primary analysis takes place in the `HDR.ipynb` Jupyter Notebook file

The dataset used for this project is the `processed.cleveland.data` file, and comes by way of the `UCI Machine Learning Repository`

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of one-tailed hypothesis testing, two-tailed hypothesis testing, tukey wise range testing, and chi-square testing
